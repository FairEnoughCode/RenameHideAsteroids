# Rename & Hide Asteroids (Переименование и скрытие астероидов)

*English version: [README.md](README.md)*

Мод для **Oxygen Not Included: Spaced Out!** Он позволяет переименовывать астероиды и прятать ненужные из списка астероидов справа, чтобы список не занимал полэкрана.

## Что делает

### Переименование

Выберите астероид на карте звёзд и нажмите карандаш в заголовке его панели, как у ракет и дупликантов. Новое имя видно в списке справа, на карте звёзд и везде в игре.

- Имя записывается в сам астероид, поэтому остаётся, даже если отключить мод.
- Символы `< > : " / \ | ? *` и точка или пробел в конце из имени убираются: игра делает из имени астероида папку для таймлапса, а Windows не принимает такие символы в именах папок.

### Скрытие из списка

Наведите мышь на строку астероида и нажмите **Скрыть**. Скрытые астероиды уходят под ссылку **+ Скрытые астероиды (N)** внизу списка: нажмите её, чтобы их увидеть, а **Вернуть** возвращает астероид в список.

- Ракеты, стоящие на скрытом астероиде, прячутся вместе с ним. Ракеты в полёте и на орбите остаются в списке.
- Пока камера на скрытом астероиде, он виден под ссылкой.
- Стартовый астероид скрыть нельзя.
- Горячие клавиши (Ё + цифра) работают и для скрытых астероидов.
- Список скрытых хранится в сохранении, у каждой колонии свой.

### Тревоги

Скрытый астероид с красной тревогой на время возвращается под ссылку, с игровым звуком и покачиванием, пока тревога не закончится. Звук играет только один раз. Жёлтые тревоги по умолчанию выключены: их всё равно видно, если раскрыть список скрытых, а включить можно в настройках.

Красная тревога бывает и на пустом астероиде, например во время метеоритного дождя или когда ракета не может сесть. Ненужные тревоги можно выключить у каждого астероида в игровой диагностике (**Диагностика → Показать все**).

## Настройки

В меню **Моды** нажмите **Настройки** у мода:

- **Скрывать астероиды** (вкл). Если выключить, мод только переименовывает, а список как в обычной игре. Скрытые астероиды запоминаются и снова скроются, когда настройку включат обратно.
- **Показывать скрытый астероид**: **При красной тревоге** (вкл), **При жёлтой тревоге** (выкл). Работают, только если включено «Скрывать астероиды».

Изменения применяются при загрузке сохранения, перезапускать игру не нужно. Файл настроек лежит в общей папке настроек модов, поэтому не пропадает при обновлении мода.

## Совместимость

- Нужно дополнение **Spaced Out!**: список астероидов есть только в нём.
- Можно добавить в уже начатую игру и отключить в любой момент: новые имена останутся, а список станет обычным.
- Рассчитан на обновления игры: мод использует игровые панели и официальные точки входа, а надпись «Скрыть» / «Вернуть» стоит ровно там, где игра пишет свой статус.

## Сборка из исходников

Нужен .NET SDK ([dotnet.microsoft.com/download](https://dotnet.microsoft.com/download)). Перед сборкой закройте игру.

1. Один раз на компьютер создайте `GamePath.props` в папке, где лежат репозитории модов (на уровень выше этой), с путём к игре, то есть к папке с `OxygenNotIncluded.exe`:

   ```xml
   <Project>
     <PropertyGroup>
       <GameDir>C:\Program Files (x86)\Steam\steamapps\common\OxygenNotIncluded</GameDir>
     </PropertyGroup>
   </Project>
   ```

   Этот файл в git не хранится.

2. Соберите мод в его папке командой `dotnet build` (или Ctrl+Shift+B в VS Code). PLib при сборке вшивается в библиотеку мода через ILRepack; оба лежат в папке `lib`, поэтому интернет для сборки не нужен. Готовый мод сам копируется в `Документы\Klei\OxygenNotIncluded\mods\Local\RenameHideAsteroids`.

3. Запустите игру, включите **Rename & Hide Asteroids** в меню «Моды» и перезапустите.
